# Project Statement

## Problem Statement
Many students and individuals note down their spending on paper or in their head, so it is hard to see how much has been spent, which category costs the most, or whether a planned budget has been crossed. A simple tool is needed to record expenses and see this information quickly.

## Scope
- A command-line program written in Python 3 using only the standard library.
- Records expenses (name, amount, category) in memory while the program runs.
- Lets the user set one budget and check spending against it.
- Produces simple reports from the recorded expenses.
- Not included: saving data between runs, dates, multiple users, graphical or web interfaces.

## Target Users
- Students and beginners who want a small tool to track personal expenses.
- Anyone who wants a quick budget check from the terminal.

## High-Level Features
- **Expense Management:** add, view, search and remove expenses.
- **Budget Management:** set a budget, see total spending and remaining budget, and get a warning when the budget is crossed.
- **Reporting:** total expense report, category-wise report, highest expense and a simple numerical summary (average, smallest, largest).
